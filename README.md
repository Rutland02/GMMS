# GMMS
健身房会员管理系统

## 健身房会员管理系统 (GMMS 2.0)

一个基于Qt框架开发的健身房会员管理系统，提供会员管理、课程预约、签到统计等功能。

本仓库同时提供一套面向 C++/Qt 初学者的教材案例。建议先阅读 [教材案例](docs/GMMS教材案例.md)，再按照 [学习路线](docs/GMMS学习路线.md) 分阶段阅读和修改代码。

## 功能特点

### 核心功能
- **会员管理**：添加、查询、编辑和删除会员信息，支持会员等级与积分系统
- **课程管理**：管理健身课程信息，支持课程编辑、删除、搜索和状态显示
- **预约系统**：会员预约课程功能，预约成功可获得积分奖励
- **签到功能**：会员签到记录，签到成功可获得积分奖励
- **统计分析**：会员活跃度、课程预约情况、积分统计等数据统计
- **积分系统**：实现积分累积、等级升级机制，支持手动积分调整

### 界面模块
- **会员标签页**：管理会员基本信息，显示和调整会员积分与等级
- **课程标签页**：管理课程信息，支持添加、编辑、删除课程，实现课程搜索筛选和状态显示
- **预约标签页**：处理课程预约，预约成功自动积分
- **查询标签页**：查询会员和课程信息
- **统计标签页**：数据可视化和统计分析，包括积分统计

## 技术栈

- **开发框架**：Qt 5.14.2
- **开发语言**：C++
- **UI组件**：Qt Widgets
- **图表组件**：Qt Charts
- **数据存储**：JSON文件
- **构建工具**：MinGW 7.3.0

## 构建说明

### 环境要求
- Qt 5.14.2 或更高版本
- MinGW 7.3.0 编译器
- Windows 操作系统

### 构建步骤

1. **打开项目**
   使用Qt Creator打开`GymManager.pro`文件

2. **配置构建套件**
   选择MinGW 7.3.0构建套件

3. **构建项目**
   ```bash
   # 清理项目
   D:/QT/Tools/mingw730_64/bin/mingw32-make clean
   
   # 构建项目
   D:/QT/Tools/mingw730_64/bin/mingw32-make
   ```

4. **运行程序**
   构建完成后运行生成的可执行文件。程序会在当前工作目录读取或创建 `gym_data.json`。

> 编译生成的 `release/`、`.o`、`.exe`、Qt Creator 配置和运行数据已加入 `.gitignore`，不会作为必要源码提交。

## 使用说明

### 会员管理
1. 进入会员标签页
2. 点击"添加会员"按钮添加新会员
3. 填写会员信息并保存

### 课程预约
1. 进入预约标签页
2. 选择会员和课程
3. 点击"预约"按钮完成预约

### 签到功能
1. 进入签到界面
2. 选择会员和课程
3. 点击"签到"按钮记录签到

### 数据统计
1. 进入统计标签页
2. 查看会员统计、课程统计和活跃度图表
3. 可选择日期范围查看特定时间段的数据

## 开发说明

### 数据持久化
系统使用JSON文件存储数据，在程序启动时加载数据，退出时保存数据。

`gym_data.json` 是本地运行数据，不在 Git 中维护。首次运行或找不到数据文件时，程序使用内置默认数据。

### 类结构
- **Member**：会员类，存储会员信息
- **Course**：课程类，存储课程信息
- **CheckIn**：签到类，存储签到记录
- **GymData**：核心数据管理类，处理数据的加载、保存和统计

### 界面设计
使用Qt Widgets和布局管理器创建响应式界面，支持多标签页操作。

## 问题与解决方案

### 常见问题
- **编译错误**：确保使用正确的Qt版本和编译器
- **链接错误**：检查是否正确包含Qt Charts模块
- **数据丢失**：确保程序正常退出，数据会自动保存

### 开发建议
- 扩展功能时保持代码结构清晰
- 遵循Qt的编程规范
- 添加适当的错误处理机制

## 版本历史

### GMMS 2.0
- 重构了数据模型，将结构体改为类
- 优化了用户界面
- 添加了数据统计和图表功能
- 改进了数据持久化机制
- **会员等级与积分系统**：
  - 实现了积分累积功能（签到+10积分，预约+5积分）
  - 自动等级升级机制（≥5000=钻石，≥2000=黄金，≥500=白银，<500=普通）
  - 会员标签页支持积分显示和手动调整
  - 统计标签页新增积分统计信息
- **课程管理优化**：
  - 扩展课程属性：新增课程类型、描述、价格等字段
  - 优化时间表示：使用结构化的星期和时间段字段
  - 课程编辑功能：支持修改课程所有属性的模态对话框
  - 课程删除功能：支持从课程列表删除选中课程
  - 搜索筛选功能：按名称、类型、教练搜索课程
  - 课程状态显示：直观显示课程是否已满（红色"已满"/绿色"可预约"）

### GMMS 1.0
- 基础的会员管理功能
- 简单的课程预约系统

## 学习说明

本项目适合用于学习 C++ 类、Qt Widgets、信号与槽、JSON 持久化、表格查询和基础统计。当前代码已经修复了表格过滤后按行号误操作、课程 ID 冲突、记录缺少课程 ID、过期课程统计不一致和 JSON 写入不安全等问题；会员等级规则、枚举化、自动化测试和 Model/View 仍作为教材中的后续练习。详细任务见 [GMMS 教材案例](docs/GMMS教材案例.md)。
